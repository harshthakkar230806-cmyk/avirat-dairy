# Avirat Dairy — Merged Project

This project combines:
- Avirat Dairy Customer + Admin UI
- Supabase database schema
- Supabase RLS policies
- Supabase browser/server/admin client setup
- Generated database types

## Important
The UI currently uses demo/mock data. The Supabase backend files are included, but the UI has not yet been wired to live Supabase queries/authentication.

Next step: connect authentication, customer orders, calendar/history, billing, payments, milk prices, and admin data to Supabase.
